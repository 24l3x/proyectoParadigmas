# Proyecto Paradigmas

## Caracteristicas ✨

- Frontend: HTML, CSS y JavaScript
- Backend: Python
- DataBase: Postgresql

## Como usarlo 🚀
Clona este repositorio: `git clone https://github.com/24l3x/proyectoParadigmas.git`

Si tienes docker engine y docker desktop instalado usa: `docker-compose up -d --build`

Si no tienes docker, puedes ver el frontend con la extension de "Live view" de Visual Studio Code o abriendo el archivo `index.html`
